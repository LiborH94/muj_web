Weby s duší… i s hudbou

Jsem Libor Hlaváč – web developer a zároveň violoncellista v Jihočeském divadle. Ve dne kóduju weby, večer hraju na pódiu. Spojuju techniku s kreativitou.

Moje práce

O mně

Jmenuji se Libor Hlaváč a pohybuji se mezi světem hudby a světem technologií. Přes den tvořím weby, večer hraju na violoncello v Jihočeském divadle. Kódování je pro mě jako hudba – má mít rytmus, logiku i emoce.

Jsem webový vývojář, který se neustále vzdělává a zdokonaluje ve svých dovednostech. Mám zkušenosti jak s frontendovým, tak s backendovým vývojem. Můj přístup k vývoji je kreativní, zaměřuji se na moderní, responzivní design s důrazem na uživatelskou přívětivost. Prioritu dávám mobile-first přístupu a neustále hledám efektivní a inovativní řešení pro každý projekt.

Co umím:

  • HTML5 a CSS3 – tvorba webových stránek a aplikací s důrazem na moderní design, responzivitu a mobile-first přístup.
  • Moderní JavaScript & TypeScript – vývoj interaktivních a dynamických aplikací s využitím moderních nástrojů.
  • React – tvorba komponent a stavového managementu pro moderní frontendové aplikace.
  • PHP (Nette) – vývoj webových aplikací s PHP a frameworkem Nette, momentálně se v této oblasti stále zdokonaluji..
  • Node.js – základní zkušenosti s vývojem backendových aplikací pomocí Node.js.
  • WordPress – vlastní šablony – tvorba a přizpůsobení šablon pro WordPress.
  • MySQL – správa databází a efektivní práce s daty.
  • Java (Spring Boot) - základní znalosti vývoje backendu a tvorby REST API pro robustní a škálovatelné aplikace.
  • Python - základní syntaxe, objektově orientované programování (OOP), experimentování s knihovnami pro různé úkoly.
  • Selenium – automatizace testování webových aplikací a interakcí s uživatelským rozhraním.
  • Git – správa verzí u projektů s použitím Git a GitHub.

V blízké budoucnosti plánuji se naučit:

  • Docker – kontejnerizace aplikací pro usnadnění vývoje, nasazení a správu.

Rád se neustále vzdělávám, testuji nové nástroje a technologie a vnímám webový vývoj jako kreativní a praktickou výzvu.
