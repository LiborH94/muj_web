Weby s duší… i s hudbou

Jsem Libor Hlaváč – web developer a zároveň violoncellista v Jihočeském divadle. Ve dne kóduju weby, večer hraju na pódiu. Spojuju techniku s kreativitou.

Moje práce

O mně

Jmenuji se Libor Hlaváč a pohybuji se mezi světem hudby a světem technologií. Přes den tvořím weby, večer hraju na violoncello v Jihočeském divadle. Kódování je pro mě jako hudba – má mít rytmus, logiku i emoce.

Momentálně se zaměřuji na moderní webové technologie a stále se učím nové věci. Mám zkušenosti se základním PHP (pro jednoduché weby a WordPress), HTML a CSS. V současnosti se zaměřuji na:

  • Moderní JavaScript & TypeScript – základy programování, React pro dynamické aplikace
  • Spring Boot (Java) – základy backendového vývoje a REST API
  • REST API – WordPress Headless – vytvářím API pro komunikaci mezi frontendem a backendem (WordPress jako headless CMS)
  • MySQL – základní práce s databázemi pro uložení a správu dat
  • Python – používám pro hraní a experimentování, zkouším různé knihovny a frameworky

Rád se neustále vzdělávám, testuji nové nástroje a technologie a vnímám webový vývoj jako kreativní a praktickou výzvu.

Co umím

  • Tvorba webů na míru (HTML, CSS, JS) – jednoduché, responzivní stránky
  • WordPress – vývoj šablon, úpravy a tvorba pluginů, včetně headless implementace pro moderní aplikace
  • React & TypeScript – tvorba moderních frontendových aplikací s využitím komponent a stavových managementů
  • Spring Boot (Java) – základní vývoj backendu a REST API pro robustní aplikace
  • REST API – vytváření a správa API pro komunikaci mezi aplikacemi, včetně headless WordPress
  • MySQL – práce s relačními databázemi, SQL dotazy pro ukládání a správu dat
  • Python – automatizace, experimentování a práce s různými knihovnami
